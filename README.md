# 우테코 프리코스 2주차 과제: 자동차 경주

## 구현 기능 목록

실행 로직 순으로 작성되었습니다.

### 1. MESSAGES / CONSTANTS

- 애플리케이션 실행, 안내, 결과, 에러 발생 시 출력할 메시지를 상수로 지정한다.
- 최대 / 최소 이름 길이를 상수로 지정한다.

### 2. Views (InputView, OutputView)

- `InputView`: `readLineAsync`를 통해 사용자로부터 자동차 이름과 시도할 횟수를 입력받는다.
- `OutputView`: 실행 결과와 최종 우승자를 정해진 형식에 맞게 출력한다.
- 예외 발생 시 에러 메시지를 출력한다.

### 3. CarParser

- 사용자로부터 입력받은 자동차 이름 문자열을 파싱한다.
- 쉼표(,)를 기준으로 문자열을 분리하여 이름 배열을 반환한다.

### 4. Car

- 자동차의 이름과 이동 거리를 상태로 가진다.
- 이름이 유효한지 검증하고, 유효할 경우에만 인스턴스를 생성한다.
- 무작위 값을 기준으로 전진 여부를 결정하고 이동 거리를 증가시키는 기능을 가진다.

### 5. Race

- 여러 `Car` 인스턴스와 시도할 횟수를 상태로 가진다.
- 경주 시작 전, 자동차 이름의 중복 여부나 참가자 수를 검증한다.
- 시도할 횟수만큼 각 자동차의 경주를 진행시키고, 라운드별 결과를 기록한다.
- 모든 경주가 끝난 후, 가장 많이 전진한 자동차를 찾아 우승자를 결정한다.

### 6. RaceController

- `View`를 통해 사용자 입력을 받고, 이를 가공하여 `Model`에 전달한다.
- `Model`을 이용해 경주를 실행시키고, 반환된 결과 데이터를 다시 `View`에 전달하여 출력을 요청한다.
- `try...catch` 구문을 통해 애플리케이션 실행 중 발생하는 예외를 처리한다.

### 7. App

- 애플리케이션의 시작점으로, `RaceController`를 생성하고 실행하는 역할을 담당한다.
